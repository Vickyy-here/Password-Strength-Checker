# Password Strength Checker

A complete, responsive Password Strength Checker web application built with semantic HTML, modern CSS, and vanilla JavaScript. It provides real-time password analysis, detailed feedback, a visual security meter, and a secure password generator.

## Features

- Real-time password strength checking while typing
- Show/Hide password toggle
- Manual **Check Strength** button
- Strength score out of 100
- Strength labels:
  - Very Weak
  - Weak
  - Medium
  - Strong
  - Very Strong
- Animated progress/security meter with color levels:
  - Red (Very Weak)
  - Orange (Weak)
  - Yellow (Medium)
  - Light Green (Strong)
  - Green (Very Strong)
- Detailed feedback checklist:
  - Uppercase letters
  - Lowercase letters
  - Numbers
  - Special characters
  - Minimum length
  - Space usage
  - Common password detection
  - Repeated character penalty
  - Sequential pattern penalty
- Password generator with options:
  - Adjustable length
  - Include uppercase/lowercase/numbers/symbols
  - Secure random generation
  - One-click copy to clipboard
- Password tips section with security best practices
- Responsive cybersecurity-themed UI for desktop, tablet, and mobile

## Technologies Used

- HTML5 (semantic structure)
- CSS3 (responsive design, dark theme, animations)
- Vanilla JavaScript (modular logic, real-time evaluation, secure generation)

## Installation Steps

1. Clone this repository:
   ```bash
   git clone https://github.com/Vickyy-here/Password-Strength-Checker.git
   ```
2. Navigate to the project directory:
   ```bash
   cd Password-Strength-Checker
   ```
3. Open `index.html` in your browser.
